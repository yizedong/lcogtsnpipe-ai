# lcogtsnpipe-ai (`snpipe`)

An IRAF-free, pure-Python rewrite of the LCOGT supernova photometry pipeline
[lcogtsnpipe](https://github.com/LCOGT/lcogtsnpipe), built to be **run and checked by AI agents**.

* Same stages, same recipes and defaults as the old pipeline — every number is taken from the old code
  (file:line references in the module docstrings); IRAF/DAOPHOT tasks are reproduced with
  photutils / astropy / scipy following the IRAF source.
* No IRAF, no SExtractor, no MySQL server, no HOTPANTS: numpy, scipy, astropy, photutils, sep,
  astroscrappy, astroquery, reproject, PyZOGY. The database is a single SQLite file with the old
  `photlco`/`targets` columns and sentinel values (9999, 'X', quality 127/1).
* Faster: one process per worker instead of one Python+IRAF process per image, no shared scratch files
  (every stage runs in parallel with `-j N`), single-pass photometry, and PyZOGY's slow bad-pixel
  interpolation replaced by an exactly equivalent separable filter (the speed fix from SLIDE).
* Agent-checkable: every stage writes per-frame `*.<stage>.qa.json` (status ok/warn/fail, metrics,
  thresholds), a stage summary `qa/<stage>-latest.json`, returns a meaningful exit code, and can render
  review packets (PNG + JSON) replacing the interactive `check*` stages; verdicts are logged.
* [ASTRA](https://astra-spec.org) record of a reduction generated by `snpipe astra`.

## Install

```bash
conda create -p envs/newpipe -c conda-forge python=3.12 numpy scipy astropy photutils sep astroscrappy \
    astroquery reproject matplotlib pyyaml requests
pip install git+https://github.com/dguevel/PyZOGY.git astra-tools
pip install -e .
export SNPIPE_DIR=/path/to/workdir     # plays the role of $LCOSNDIR
export LCO_API_KEY=...                 # only for downloads of proprietary data
```

## Stages (old `lscloop.py -s ...` → `snpipe ...`)

| stage | command | what it does | agent gate |
|---|---|---|---|
| ingest | `snpipe ingest --target NAME --start ... --end ...` | LCO archive query (or local files), funpack-equivalent unpacking, photlco rows | frames placed == queried |
| catalogs | `snpipe catalogs --target NAME` | APASS DR9, SDSS (or PS1 `--sloan-source panstarrs`), Gaia DR3 | catalog found |
| wcs | `snpipe wcs -n NAME -e EPOCH` | verify BANZAI WCS against Gaia, refit when needed | rms ≤ 2″, ≥10 matches |
| cosmic | `snpipe cosmic ...` | astroscrappy, sigclip 4.5 / sigfrac 0.2 / objlim 4 | CR fraction |
| psf | `snpipe psf ...` | PSF model + aperture correction + sn2 table, remediation ladder | \|apco\| ≤ 0.1 |
| psfmag | `snpipe psfmag ...` | target PSF + aperture photometry, background iterations | fit converged, on target |
| zcat | `snpipe zcat -f landolt --field apass ...`, `-f sloan` | zero point + colour term | ≥5 stars kept |
| mag | `snpipe mag ...` | calibrated magnitudes (colour solved per night) | mag defined |
| template | `snpipe template ...` | mark reference frames (filetype 4) | |
| diff | `snpipe diff -T fa --temptel fl --tempdate ...` | PyZOGY difference images | residual statistics |
| getmag | `snpipe getmag ... -o lc.csv` | light-curve table (CSV + ECSV with frame names) | |
| review | `snpipe review psf --ensemble apco` | queue of warn/fail + spot-check frames with PNG packets | |
| verdict | `snpipe verdict FRAME psf redo --param fwhm=7 --reason ...` | y/n/b/d/u effects of the old interactive checks, logged | |
| astra | `snpipe astra NAME --ra --dec --epoch --tempdate ...` | ASTRA record of the reduction | `astra validate` |

Exit codes: 0 ok, 1 QA fail on ≥1 frame, 2 configuration error, 3 missing input, 4 external service failure.

## Typical reduction (difference imaging, as in Singh et al. 2026 for SN 2024pxl)

```bash
snpipe add-target 2024pxl --ra 263.113958 --dec 7.062411 --alias SN2024pxl
snpipe ingest --target SN2024pxl --start 2024-07-22 --end 2024-11-10
snpipe catalogs --target 2024pxl
snpipe cosmic -n 2024pxl -e 20240722-20241110
snpipe psf    -n 2024pxl -e 20240722-20241110
# references: frames taken 2018-03-07
snpipe template -n 2024pxl -e 20180306 && snpipe cosmic -n 2024pxl -e 20180306 --filetype 4
snpipe psf -n 2024pxl -e 20180306 --filetype 4
snpipe diff -n 2024pxl -e 20240722-20241110 --tempdate 20180306 --temptel fl
snpipe psf    -n 2024pxl -e 20240722-20241110 --filetype 3
snpipe psfmag -n 2024pxl -e 20240722-20241110 --filetype 3
snpipe zcat   -n 2024pxl -e 20240722-20241110 --filetype 3 -f landolt --field apass --type ph
snpipe zcat   -n 2024pxl -e 20240722-20241110 --filetype 3 -f sloan --type ph
snpipe mag    -n 2024pxl -e 20240722-20241110 --filetype 3 --type ph
snpipe getmag -n 2024pxl -e 20240722-20241110 --filetype 3 --type mag -o lc.csv
```

See `docs/agents.md` for how an agent drives and checks a reduction, `docs/decisions.md` for every
place where the new pipeline deliberately differs from the old one, and `docs/report/` for the
stage-by-stage comparison with the old pipeline on SN 2024pxl.
